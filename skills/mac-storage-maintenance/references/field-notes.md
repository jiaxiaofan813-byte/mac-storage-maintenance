# 从实际清理中总结的排查案例

| 现象 | 怎么定位与验证 |
|---|---|
| Chrome 更新后又占内置盘 | 核对应用入口是链接还是实体，检查更新器登记与版本目录。签名问题先区分 Finder 元数据、生成文件和受签名保护的内容。在副本上做最小修复，重新验证原厂签名、启动和现有用户资料。 |
| Blender 后台测试成功，图形界面却卡住 | 对照应用临时目录偏好和图形进程的环境，检查外置卷权限提示。确认正常打开、保存和重启后再处理本机回退件。 |
| Obsidian 迁移后停在加载 | 核对默认打开的是实际知识库，检查 iCloud 占位和离线下载状态。恢复所需文件后验证索引和重启。 |
| Final Cut Pro 新资源库写回内置盘 | 按资源库检查媒体、Motion 内容、缓存和备份位置。重启后回读设置，再验证真实生成的缓存。 |
| 下载文件夹已分批搬过，现要迁整个目录 | 按每个入口判断其指向的实际文件。合并同名有效目标时保留目标实体，保留指向旧归档的链接，避免自指和重名覆盖。 |
| 同版本模拟器显示两份 | 对照 build 和关联设备；显示名称相同的运行环境可能支持不同设备。设备数据与运行环境单独盘点。 |
